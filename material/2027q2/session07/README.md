# Session 07 — GPT hands-on with Karpathy's Zero to Hero #1 (Week 7)

Based on Andrej Karpathy's *Neural Networks: Zero to Hero*, lecture
"Let's build GPT: from scratch, in code, spelled out"
(https://karpathy.ai/zero-to-hero.html — code: github.com/karpathy/nn-zero-to-hero,
nanoGPT). In the 2026 edition this video was assigned as preparation after
session06; here it becomes the backbone of sessions 07-08.

Linguist-friendly format: students do NOT reimplement GPT from scratch.
They read the reference code and get their hands on it by modifying or
writing a specific part (e.g. the attention block in `model.py`).

Planned content:
- recap: bigram model -> neural net -> transformer decoder (video up to ~1:19)
- walkthrough of nanoGPT `model.py`: token/position embeddings, blocks, attention, LM head
- guided exercise: modify or write one component (e.g. an attention head)

Exercise: **Ex 3 handed out** — see `ex3.md` (template from the 2026 edition).
